# ClearWork — інструкція для користувача

Ця інструкція призначена для підприємства, яке встановлює ClearWork самостійно.

## Що входить у поставку

- установник `ClearWork-Setup-0.8.3.exe`
- локальна програма для обліку охорони праці на одному комп'ютері
- окремий ключ установки для вашого ПК

Python окремо встановлювати не потрібно.

## Встановлення

1. Запустіть `ClearWork-Setup-0.8.3.exe`.
2. Якщо Windows показує попередження SmartScreen:
   - натисніть `Докладніше`
   - потім `Все одно запустити`
3. Завершіть майстер установки.
4. За потреби увімкніть демонстраційний режим лише для ознайомлення з програмою.

Рекомендовано, щоб установку виконував системний адміністратор підприємства.

## Перший запуск

1. Запустіть ClearWork з меню Пуск.
2. На екрані активації знайдіть **ID установки**.
3. Надішліть ID установки та назву підприємства розробнику:
   - email: alexeyovch26@gmail.com
   - телефон: +380954553545
4. Отримайте ключ установки (`CW-...`) і вставте його в поле активації.
5. Після активації задайте паролі інспектора і керівника (мінімум 8 символів).
6. Збережіть файл recovery окремо від папки програми.

Ключ установки потрібен один раз для цього комп'ютера. Після активації повторно не запитується.

## Де зберігаються дані

За замовчуванням ClearWork зберігає робочі дані поруч із програмою:

- `%LOCALAPPDATA%\Programs\ClearWork\data\` — база даних
- `%LOCALAPPDATA%\Programs\ClearWork\data\backups\` — резервні копії
- `%LOCALAPPDATA%\Programs\ClearWork\data\recovery\` — файли відновлення доступу
- `%LOCALAPPDATA%\Programs\ClearWork\logs\` — технічний журнал

Файл `data\osah.sqlite3` містить усі ваші робочі записи.

## Резервні копії

- Програма створює автоматичну резервну копію раз на день при запуску.
- Додаткову копію можна створити в розділі **Налаштування**.
- Перед оновленням або перевстановленням зробіть резервну копію вручну.

## Оновлення програми

1. Закрийте ClearWork.
2. Запустіть новий установник поверх старої версії.
3. **Не видаляйте** папку `data\`, якщо хочете зберегти робочі дані.

Детальні рекомендації до оновлення надає розробник разом із новою версією.

## Перевстановлення

- Якщо папку `data\` не чіпати, дані зазвичай зберігаються.
- Якщо `data\` видалено або змінено комп'ютер, з'явиться новий **ID установки** і знадобиться новий ключ установки.

Перепривязка ключа — через розробника, один раз після звернення.

## Демонстраційний режим

Якщо під час установки було увімкнено демонстраційний режим, у базі з'являться тестові дані.

Для робочої установки:
1. перевстановіть програму без демо-режиму;
2. за потреби видаліть стару папку `data\` перед чистою установкою.

Ключ установки діє для будь-якого режиму на цьому ПК.

## Щоденний звіт

ClearWork не надсилає звіт поштою автоматично. У заданий час з'явиться нагадування сформувати файл; відправка — лише вручну.

## Конфіденційність і відповідальність

ClearWork працює локально на комп'ютері підприємства. У базі можуть зберігатися персональні та службові дані працівників.

Підприємство самостійно відповідає за:
- доступ до комп'ютера з програмою;
- збереження резервних копій;
- передачу файлів `data\`, recovery та експортів третім особам.

2. Запустіть `ClearWork.exe` напряму з папки програми.
3. Перевірте, чи з'явились папки `data\` і `logs\`.
