# ClearWork — чеклист встановлення та пілоту

Коротка інструкція для розробника та довірених продажів перед передачею програми клієнту.

Версія поставки: **1.1.3**

---

## A. Перед передачею клієнту (розробник)

### Збірка інсталяторів

- [ ] Зібрати exe: `powershell -ExecutionPolicy Bypass -File installer\build_clearwork.ps1`
- [ ] Зібрати demo: `powershell -ExecutionPolicy Bypass -File installer_DEMO\build_clearwork.ps1`
- [ ] Перевірити наявність файлів:
  - `installer\ClearWork-Setup-1.1.3.exe`
  - `installer_DEMO\ClearWork-Demo-Setup-1.1.3.exe`
  - `installer\ClearWork_швидкий_старт.pdf` (генерується під час збірки)
- [ ] Key Admin готовий: `tools\clearwork_key_admin\ClearWorkKeyAdmin.exe` (або запуск з Python)

### Що передати клієнту

| Сценарій | Файл | Ключ установки |
|----------|------|----------------|
| Ознайомлення (48 год) | `ClearWork-Demo-Setup-1.1.3.exe` | Не потрібен |
| Пілот / робота | `ClearWork-Setup-1.1.3.exe` | Потрібен після отримання ID |
| Документація | У комплекті з установщиком: `ClearWork_швидкий_старт.pdf`, `ClearWork_користувач.md` | — |

### Попередження для клієнта (обов'язково озвучити)

- [ ] Windows SmartScreen може показати попередження — це нормально без цифрового підпису
- [ ] Програма працює **локально**, дані на комп'ютері підприємства
- [ ] Папку `data\` не видаляти — там ID установки, база та таймер demo

## B. Демонстраційна установка (ClearWork-Demo-Setup)

**Мета:** показати можливості програми без ключа, 48 годин.

### Установка

- [ ] Запустити `ClearWork-Demo-Setup-1.1.3.exe`
- [ ] При SmartScreen: `Докладніше` → `Все одно запустити`
- [ ] Обрати каталог (можна диск D:, E: — не лише C:)
- [ ] На фінальному кроці: «Відкрити інструкцію» (увімкнено за замовчуванням), «Запустити ClearWork Demo» — за бажанням

### Перший запуск

- [ ] Екран **без** ключа установки — одразу налаштування паролів
- [ ] Задати паролі інспектора та керівника (мін. 8 символів; для demo — будь-які)
- [ ] Зберегти recovery-файл
- [ ] Увійти під інспектором

### Перевірка даних

- [ ] Дашборд відкрився, є сповіщення / метрики
- [ ] Розділ «Працівники» — демо-список заповнений
- [ ] «Інструктажі», «СИЗ», «Медогляди», «Наряди» — є записи
- [ ] PORT-R — реєстр ризиків (306 записів) доступний
- [ ] Верхній баннер: «Демонстраційна версія · залишилось …»
- [ ] «Про програму» — блок про 48-годинний період

### Обмеження demo (перевірити за бажанням)

- [ ] Створення резервної копії — **працює**
- [ ] Відновлення з копії — **заблоковано** (очікувана поведінка)
- [ ] Після 48 год — блокування з контактами розробника

## C. Пілотна / робоча установка (ClearWork-Setup)

**Мета:** реальна експлуатація з ключем установки.

### Установка

- [ ] Запустити `ClearWork-Setup-1.1.3.exe`
- [ ] **Не** вмикати галочку «Демонстраційний режим» (для робочої бази)
- [ ] Обрати каталог установки
- [ ] На фінальному кроці відкрити `ClearWork_швидкий_старт.pdf` перед першим запуском
- [ ] Завершити майстер

> Галочка «Демонстраційний режим» — лише тестові дані **з ключем**, без таймера. Для короткого ознайомлення без ключа використовуйте Demo-Setup.

### Активація

- [ ] Запустити ClearWork
- [ ] Скопіювати **ID установки** (або зберегти файл запиту на ключ)
- [ ] Надіслати ID + назву підприємства розробнику:

  - телефон: +380954553545
- [ ] Отримати ключ `CW-...`, вставити, активувати
- [ ] Задати паролі, зберегти recovery

### Перевірка роботи

- [ ] Вхід інспектором і керівником
- [ ] Додати тестового працівника / запис інструктажу
- [ ] Створити резервну копію в налаштуваннях
- [ ] Експорт docx (PORT-R, звіт) — за потреби сценарію клієнта
- [ ] Перезапуск програми — вхід без повторного ключа

### Після переустановки на тому ж ПК

- [ ] **Не видаляти** папку `data\` — збережеться активація та ID
- [ ] Якщо `data\` видалено — новий ID, потрібен новий ключ (звернення до розробника)
